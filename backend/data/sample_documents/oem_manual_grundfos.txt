MECHANICAL SEAL SYSTEM
Primary Seal Configuration: Cartridge-type mechanical seal

Primary Seal Spring: Stainless steel Belleville spring, preloaded
Secondary Seal Material: FKM (Viton fluoroelastomer) Type B cartridge
Secondary Seal Application: Pressure-balanced secondary seal for high-pressure operation
Secondary Seal Faces: Tungsten carbide (rotating) on carbon (stationary)
Seal Cavity Pressure: Balanced cavity design allows operation to 25 bar without damaging seals
Acceptable Leakage Rate: <0.5 mL/day (per ISO 4414)
Seal Lubrication: Via pumped process fluid (ISO VG 32 hydraulic oil)
Seal Service Life (Design): 24-36 months (actual 20-24 months in industrial steel plant duty)

Seal Replacement Procedure:
  1. Isolate pump from system (close inlet/outlet ball valves)
  2. Relieve all system pressure using manual bleed
  3. Remove seal cavity plug from pump body (1/4" NPT port on side)
  4. Withdraw seal cartridge assembly using seal removal tool (Grundfos P/N 96088021)
  5. Inspect seal cavity cleanliness (flush to ISO 4406 16/14/11 if required)
  6. Install new seal kit (primary + secondary cartridge assembly) using seal compression tool
  7. Torque seal cavity plug to 25 N-m
  8. Refill system and pressurize to 5 bar to verify no external leakage before full operation

SECTION 2: TROUBLESHOOTING GUIDE
================================================================================

PROBLEM 1: PUMP WILL NOT START (Motor does not hum)

Symptom Description: Green START button pressed, pump motor does not rotate or produce sound

Diagnostic Steps:
  Step 1: Verify main electrical supply
    - Check that main breaker is in ON position
    - Use multimeter: Verify 220V between phase terminals (L1-L2, L2-L3, L1-L3)
    - Check voltage imbalance: All three phases should read 215-225V nominal
    - If voltage <200V: Contact power company (low supply voltage)
    - If voltage >240V: Check transformer tap settings (may damage motor)
  
  Step 2: Verify emergency stop circuit
    - Locate red STOP button on control panel
    - If button is pressed inward (STOPPED state): Turn counterclockwise to RESET
    - Listen for click sound confirming reset (electrical contact closure)
    - Retry START button
  
  Step 3: Check motor circuit protection
    - Locate motor circuit breaker (typically 10A type C three-phase breaker)
    - If breaker is in TRIPPED position (lever in middle): Reset to ON
    - If breaker trips immediately after reset: Do NOT retry
      Root cause likely electrical fault - Contact maintenance supervisor
      Troubleshooting required: Motor megohm test, phase sequence verification
  
  Step 4: Verify motor soft starter (if installed)
    - Some systems have electronic soft starters reducing inrush current
    - Check soft starter panel for red fault light (indicates fault code)
    - Soft starter fault codes: Consult equipment manual or technician
  
  Step 5: Motor insulation test (Megohm test - requires technician)
    - If Steps 1-4 pass but motor still won't start:
    - Use megohm tester: Phase-to-ground insulation should read >10 MΩ
    - If insulation <10 MΩ: Motor winding failure suspected - Replace motor
    - If insulation good: Check motor connector terminals (loose connections possible)

Root Causes Summary: Low supply voltage (10%), emergency stop active (40%), circuit breaker tripped (30%), motor winding failure (15%), loose connectors (5%)

PROBLEM 2: PUMP STARTS BUT NO PRESSURE BUILDS (Gauge stays at 0 bar)

Symptom Description: Motor runs (audible humming), pump audibly operates, but discharge pressure gauge reads 0 bar

Diagnostic Steps:
  Step 1: Verify flow (audible/visual)
    - Listen at discharge hose outlet (if accessible)
    - Expected: Fluid flow sound (rushing water-like sound)
    - If no flow sound: Pump is cavitating or intake blocked
    - If flow sound present: Pump delivering flow (pressure build failure likely)
  
  Step 2: Check discharge ball valve
    - Locate discharge ball valve (on discharge piping, ~0.5m from pump outlet)
    - Turn handle: Should align parallel to pipe (OPEN position)
    - If handle perpendicular to pipe: Valve is CLOSED
    - Action: Turn handle to parallel position, try pressure ramp again
  
  Step 3: Check inlet ball valve
    - Locate inlet ball valve (on inlet piping, ~1.0m from pump inlet)
    - Turn handle: Should align parallel to pipe (OPEN position)
    - If handle perpendicular: Valve is CLOSED - flow blocked at inlet
    - Action: Turn handle to parallel position
  
  Step 4: Verify pump is actually rotating
    - Look at pump coupling guard: Can you see coupling rotation?
    - Listen to pump body: Audible rotating sound with pitch consistent?
    - If no rotation visible/audible: Motor spinning but coupling slipped
      Likely cause: Flexible coupling damper degraded or bolts loose
      Action: Stop pump, inspect coupling 4 bolts (tighten if loose)
  
  Step 5: Check for inlet blockage (cavitation)
    - Look at inlet pressure gauge (should read 2.0-2.5 bar normally)
    - If inlet pressure <0.5 bar: Inlet blockage or cavitation occurring
    - If inlet pressure normal (2.0-2.5 bar): Problem is discharge-side
  
  Step 6: Diagnose discharge-side blockage
    - If inlet pressure good BUT discharge pressure is 0 bar:
    - Stop pump and listen for blockage noise (grinding sound indicates impeller blockage)
    - Feel discharge hose (if safe temperature-wise): Should feel pressure pulsation
    - If hose is soft/no pulsation: Pump outlet blocked (restriction in downstream system)
    - Action: Check if downstream check valve is stuck closed
    - Action: Verify cooler inlet/outlet valves are OPEN

Root Causes Summary: Discharge valve closed (35%), inlet valve closed (25%), inlet cavitation (20%), coupling slip (10%), downstream blockage (10%)

PROBLEM 3: CAVITATION EVENT (Audible grinding/crackling noise from pump)

Symptom Description: Pump operating, audible cavitation noise "grinding" or "crackling" sound

Causes of Cavitation:
  Cause 1: Inlet strainer blockage (80% of cavitation cases)
    Symptom: Noise develops gradually, inlet pressure drops below 1.5 bar
    Solution: Clean or replace inlet strainer element (40 micron)
    Time to resolution: 15-20 minutes (strainer cleaning/replacement)
  
  Cause 2: Insufficient inlet pressure (suction starvation)
    Symptom: Noise develops when pump load increases, inlet pressure <0.5 bar
    Root cause: Reservoir fluid level low, inlet line restriction, pump inlet below fluid level
    Solution: Verify reservoir fluid level adequate, check inlet line for blockage
    Time to resolution: 5-10 minutes
  
  Cause 3: Elevated bulk oil temperature
    Symptom: Cavitation noise appears when fluid temperature >58°C
    Root cause: Inadequate cooler capacity, cooler fan not operating
    Solution: Verify cooler fan running, check cooler outlet for blockage
    Time to resolution: 10-15 minutes (cooler diagnosis)
  
  Cause 4: Inlet line restriction (unusual)
    Symptom: Cavitation noise, inlet pressure very low (<0.5 bar)
    Root cause: Inlet hose kinked, inlet coupling partially disconnected, inlet strainer bypass opened
    Solution: Visually inspect inlet line from reservoir to pump inlet
    Time to resolution: 5 minutes (visual inspection)

Immediate Response (All Causes):
  1. STOP pump immediately when cavitation detected (pressure release, no more noise generation)
  2. Wait 2 minutes for system pressure to drop to zero (cooling period)
  3. IDENTIFY CAUSE using diagnostic steps above
  4. DO NOT restart until root cause addressed
  5. After fix, restart using normal startup procedure (STEP 5 in SOP-42A)

Cavitation Risk Assessment:
  - If cavitation continues <30 minutes: Minor impeller pitting risk, seals protected
  - If cavitation continues 30-60 minutes: Significant impeller erosion, shaft runout increase risk
  - If cavitation continues >2 hours: Impeller fatigue failure probable, seals at risk if pressure-balance compromised
  - Post-cavitation inspection: Always measure impeller wear (ultrasonic thickness test), bearing condition

Cavitation Prevention:
  - Maintain inlet pressure >1.5 bar at all times
  - Keep strainer clean (replace when inlet pressure rises >0.5 bar above baseline)
  - Monitor bulk oil temperature (max 60°C, alarm at 58°C)
  - Maintain proper reservoir level (never below MIN mark on gauge)
  - Keep inlet line free of restrictions (inspect annually)

PROBLEM 4: SEAL FAILURE (Continuous fluid weeping or spray from drain line)

Symptom Description: Continuous fluid flow from pump drain line (not drops, but continuous stream)

Diagnostic Assessment:
  Normal (Acceptable): 1-5 drops per minute from drain line = Healthy seals
  Caution (Monitor): 5-15 drops per minute = Borderline condition, monitor closely
  Failure (STOP): Continuous stream from drain = Seal failure, DO NOT operate

Root Causes of Seal Failure:
  Cause 1: Seal mechanical wear (age >24 months)
    Symptom: Leakage rate increases gradually over weeks
    Solution: Replace seal cartridge assembly (NBR primary + FKM secondary)
    Time to resolution: 4 hours (seal replacement procedure)
  
  Cause 2: Seal cavity contamination (particulate damage)
    Symptom: Sudden increase in leakage after pressure spike or cavitation event
    Diagnosis: Clean seal cavity flush test (see SEAL REPLACEMENT procedure above)
    Solution: Flush seal cavity to ISO 4406 16/14/11, replace seals if damaged
  
  Cause 3: Seal faces cracked or pitted (cavitation damage or debris impact)
    Symptom: Large volume of leakage immediately after cavitation or pressure transient
    Diagnosis: Disassemble and visually inspect seal faces
    Solution: Replace seal cartridge immediately (damaged faces not repairable)
  
  Cause 4: Thermal degradation of seal elastomer (bulk oil temperature >65°C)
    Symptom: Leakage appears suddenly when temperature exceeds 60°C
    Root cause: NBR seal (primary) degradation at high temperature, or FKM seal loss of elasticity
    Solution: Reduce bulk oil temperature using cooler, replace seals before restarting
    Prevention: Implement temperature monitoring with 60°C alarm

Seal Leakage Limits (ISO 4414):
  Acceptable leakage: <0.5 mL/day (internal erosion balance design normal)
  Marginal leakage: 0.5-2.0 mL/day (monitor, prepare for seal replacement)
  Failure threshold: >2.0 mL/day (immediate seal replacement required)

Seal Replacement Kit:
  Part Number: Grundfos Seal Kit P/N 96087010 (complete NBR primary + FKM secondary)
  Alternative P/N by component:

PROBLEM 5: EXCESSIVE TEMPERATURE RISE (Fluid temperature >60°C, rising at >1°C per minute)

Symptom Description: Outlet thermometer reading rises rapidly during operation

Causes & Solutions:
  Cause 1: Cooler not functioning (fan not running)
    Diagnosis: Visually inspect cooler unit fan (should be rotating if temp >54°C)
    Solution: Check cooler power supply, thermostat setting, fan motor operation
    Recovery: Allow pump to idle at low pressure until temperature cools to 50°C
  
  Cause 2: Cooler outlet blocked (cooler bypass or restriction)
    Diagnosis: Feel cooler outlet hose temperature (should be warm, 3-5°C cooler than inlet)
    If outlet cold: Cooler bypass valve may be stuck, isolating cooler
    Solution: Manually open cooler isolation valve (if equipped), verify bypass valve operation
  
  Cause 3: System overload (excessive pump flow/pressure)
    Diagnosis: Check that load control valve is fully open (not restricting flow)
    Check discharge pressure: If >25 bar, system is under heavy load
    Solution: Reduce pump load temporarily by closing load valve 1/4 turn
  
  Cause 4: Low fluid level (reduces cooler effectiveness)
    Diagnosis: Check reservoir level gauge (should be between MIN and MAX)
    If low: Cooler cannot circulate adequate flow, temperature rises
    Solution: Top-up fluid to MAX level before operation resumes
  
  Cause 5: Cooler capacity inadequate for duty cycle
    Diagnosis: If all other checks pass, cooler may be undersized for continuous operation
    This was identified post-Jan 2024 cavitation incident (hot steel plant environment)
    Solution: Upgrade cooler (Grundfos recommendation: 20 kW cooler for steel plant duty)

Temperature Alarm Response:
  If fluid temperature exceeds 60°C:
    1. Stop pump operation immediately
    2. Identify root cause using diagnostics above
    3. Allow 30-minute cool-down period
    4. Restart only after cause is corrected

Prevention:
  - Install temperature alarm at 58°C (alerts operator before critical 60°C reached)
  - Ensure cooler fan is running whenever bulk oil temperature exceeds 54°C
  - Monitor monthly temperature trends (increasing trend indicates cooler degradation)

PROBLEM 6: ABNORMAL VIBRATION (Hand-feel pump body vibration >7 mm/s or audible noise)

Symptom Description: Vibration felt on pump body, unusual grinding or whining noise

Causes:
  Cause 1: Bearing wear (bearing internal play increased)
    Symptom: Low-frequency vibration (1-10 Hz), felt at pump body
    Diagnosis: Bearing runout test (place dial indicator on shaft, rotate by hand)
    Runout >0.1 mm TIR = Bearing wear significant
    Solution: Replace bearing cartridge (SKF 6205-2RS)
  
  Cause 2: Impeller imbalance (blade erosion from cavitation)
    Symptom: High-frequency vibration (1450 RPM fundamental frequency ~24 Hz)
    Diagnosis: Vibration frequency matches motor speed (indicates impeller imbalance)
    Solution: Replace impeller (Grundfos P/N for 150 mm bronze impeller available)
  
  Cause 3: Misalignment (pump/motor coupling not concentric)
    Symptom: Vibration increases with speed, coupling gets hot
    Diagnosis: Check coupling bolts (4 bolts, all should be hand-tight)
    Solution: Loosen bolts, re-align coupling, re-torque bolts to 15 N-m
  
  Cause 4: Loose foundation bolts (pump not rigidly mounted)
    Symptom: Vibration mainly felt at pump base
    Diagnosis: Visual inspection of 4 foundation bolts (M12 bolts into concrete)
    Solution: Tighten foundation bolts (hand-tight, do not over-torque threaded inserts)

Vibration Severity Scale (ISO 10816-1):
  Zone A (Normal): <2.3 mm/s RMS vibration - Equipment operating normally
  Zone B (Caution): 2.3-7.1 mm/s - Acceptable with restrictions, investigate if worsening
  Zone C (Alarm): 7.1-11.2 mm/s - Abnormal, operation should be stopped, repair needed
  Zone D (Emergency): >11.2 mm/s - Imminent failure risk, immediate shutdown required

PROBLEM 7: PRESSURE RELIEF VALVE LEAKING (Discharge pressure cannot rise above ~20 bar)

Symptom Description: System pressure plateaus at ~20 bar despite full load applied

Causes:
  Cause 1: Relief valve cracking at lower pressure (valve wear)
    Symptom: Pressure rises to ~20 bar then audible hissing (relief discharge)
    Diagnosis: Relief valve should not crack until 32 bar setpoint
    Solution: Relief valve requires recalibration by certified technician (TÜV Süd)
    Replacement: If valve cannot be recalibrated, replace with new ATOS DHRZ-A-030-210
  
  Cause 2: Relief valve partially stuck open (dirt contamination)
    Symptom: Pressure rises to 20 bar, then slowly drifts down (5-10 minutes)
    Solution: Flush relief valve cavity, clean internal poppet
    If cleaning unsuccessful: Replace valve cartridge
  
  Cause 3: Pilot line blockage (if pilot-operated relief)
    Symptom: Pressure does not rise at all (zero bar)
    Diagnosis: Check pilot supply filter (if equipped)
    Solution: Clean pilot filter, verify pilot line flow

Relief Valve Maintenance:
  - Annual calibration due: Verify setpoint ±1 bar accuracy
  - Certified technician required for recalibration (TÜV, no in-house recalibration)
  - Calibration cost: INR 3,500 (typical service charge)
  - Lead time: 4-5 working days
  - Spare cartridge availability: Keep 1 spare ATOS cartridge in inventory (INR 2,200)

SCHEDULED MAINTENANCE INTERVALS (Per Grundfos Recommendations)

Quarterly Inspection (Every 3 months or 500 operating hours):
  - Visual inspection for leaks (drain line, seal cavity, flange areas)
  - Pressure gauge reading verification (compare to baseline)
  - Temperature reading (normal range 50-55°C)
  - Audible check (listen for abnormal noise)
  - Cost: INR 0 (inspection only, no parts)

Semi-Annual Maintenance (Every 6 months or 1,000 operating hours):
  - Oil top-up (if required, <2.3 L per change)
  - Filter element inspection (change if pressure drop >2.5 bar)
  - Bearing inspection (listen for grinding, measure vibration)
  - Seal leakage measurement (count drops per minute)
  - Cost: INR 2,000-4,000 (depending on parts replacement)

Annual Maintenance (Every 12 months):
  - Hydrostatic pressure test (25 bar x 10 minutes, verify no leakage)
  - Relief valve calibration verification (±1 bar accuracy)
  - Pressure gauge calibration (verify accuracy ±2%)
  - Bearing clearance check (endplay measurement)
  - Complete seal inspection (visual examination of drain line condition)
  - Cost: INR 5,000-8,000

Major Overhaul (Every 24 months or 2,000 operating hours):
  - Complete pump disassembly
  - Bearing replacement (preventive)
  - Seal cartridge replacement (preventive, before failure)
  - Impeller wear assessment (ultrasonic thickness or visual pitting)
  - Shaft inspection (runout measurement, surface inspection)
  - Complete assembly, leak test, operational test
  - Cost: INR 12,000-15,000 (parts + labor)

Extended Overhaul (Every 60 months or 5,000 operating hours):
  - Complete pump re-manufacture (if applicable)
  - Hose assembly replacement (5-year service life expiration)
  - Cooler inspection and servicing
  - Motor bearing re-lubrication (if not sealed)
  - Cost: INR 25,000-35,000
